How the course works

Each week is one theme; each lesson is one major concept with numbered, copy-pasteable tasks a junior developer can follow end to end. Every lesson has four fixed parts:

  • The concept — what the mechanism is and the problem it exists to solve.
  • In the real system real system — the exact files, tools, and rules in the C2C Ono repo (C2C_Ono_AIR310054) that implement the full-size version. Keep the real repo open in a second window; the course is a guided tour of it as much as a build.
  • Tasks — step-by-step instructions with the code that matters written out in full.
  • Checkpoint ✓ — a concrete "you are done when…" you can verify mechanically, in the spirit of the system you're cloning: verify, don't assume.

Lessons build strictly on each other — the state machine you write in week 2 guards the statuses week 6's gates protect; the wave planner from week 5 orders the services you build in week 8. Don't skip.

Prerequisites & setup (do this before week 1)

  • Comfortable-ish with Go basics and one JS framework; everything else is taught in place.
  • Install: Go ≥ 1.22, Node ≥ 20, git, Docker (from week 1 — Memgraph runs in a container), SQLite CLI (sqlite3, for the week-8 capstone services' own data), Claude Code (week 4 on).
  • Clone access to the real repo (C2C_Ono_AIR310054) for the "in the real system" cross-reads — read-only is fine.
  • Create your workspace: mkdir mini-dde && cd mini-dde && git init. All paths in the course are relative to this root.

Ground rules (borrowed from the system you're cloning)

  • Graph first. From week 4 on, query your graph before grepping your files — the discipline of .claude/rules/bld-knowledge-graph-first.md.
  • No stubs, no shortcuts. Every lesson's code compiles and its checkpoint passes before you move on (bld-no-stubs.md, bld-no-shortcuts.md).
  • Verify, don't assume. Run the test, read the output. "It compiles" is not "it works" (universal-agent-behaviors.md §7).
  • Capture friction. From week 3 on, when something surprises you, register a Finding in your own graph. Eat the dog food.

Why this course exists as a build, not a reading list

Every mechanism in DDE was forced into existence by a concrete failure: an audit agent recommended committing straight to main because the policy lived in three partial places with no citable decision; a whole SPA was built to the text spec while ignoring every Figma frame; two PRs reached auto-merge with 19 unanswered review findings; a manually queued CD run executed a full Terraform destroy of a live environment. Each week's "why it exists" callouts tell these war stories. When you've rebuilt the guard yourself, you'll never wonder why the real one blocks you.
