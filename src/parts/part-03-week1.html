Week 1 · Part I — the graph kernel

The graph is the truth

DDE's founding bet: the durable record of a software project — its decisions, responsibilities, contracts, findings — lives in a queryable graph, not in tickets, wikis, or people's heads. This week you internalize why, then build the smallest honest version: a project-scoped node/edge store in Go over Memgraph (Cypher over the Bolt protocol — the same query language and driver family as the real system), with a CLI.

  • Concept: the four planes — intent, context, mechanism, state
  • Build: internal/graph — nodes, edges, queries in Cypher
  • Build: a minidde CLI with JSON output
  • Habit: idempotent MERGE writes, project scoping by construction
1.1The four planes of DDE — orientation & setupworldview▶

Nexus DDE ("Decision-Driven Engineering") is not one tool — it's four planes that stay deliberately separate. Intent lives in decision records (xDRs) on disk. Context lives in always-loaded rules that put constraints in every agent session. Mechanism lives in hooks, lints, and gates that block bad writes. State lives in the knowledge graph, which every agent queries before touching files. Confusing the planes is the root failure DDE prevents: a rule without a decision record is authority from nowhere; a decision without enforcement is a wish; state kept in prose is state nobody can query.

In the real system

docs/governance-framework.md §1 draws the four-plane diagram; CLAUDE.md § "Knowledge graph (single source of truth)" mandates graph-before-files; the hosted graph is reached via the dde MCP server (110 tools, Neo4j behind it). The one-way hierarchy — xDR → .claude/rules/ → enforcement — is formalized in ADR-ono-xdrs-source-ESHJ: implementation layers cite the decision they implement and never author authority themselves.

Why it exists

Before Ono relocated authority into its own xDRs, vocabulary came from an upstream repo whose own files disagreed on the spine identifier, and questions raised upstream had no SLA — one open term cost ~2h of agent time in a single day. The conclusion recorded in ADR-ono-xdrs-source-ESHJ: "the authority chain has been ceremonial." Plane separation with a one-way hierarchy is the fix, and your mini-DDE will enforce it too.

1.2A node store on Cyphercreate_node▶

A graph node in DDE is deliberately generic: an id, a type (Responsibility, Finding, Decision… — stored as the node's label), a status, and a bag of properties. The store bakes the project_id in at construction so no caller can forget it, and writes are idempotent merges: MERGE … ON CREATE SET n += $props ON MATCH SET n += $props — creating a node that exists updates its properties instead of erroring, which is what lets agents safely retry. This is not an approximation of the real system; it's the same statement shape against the same wire protocol.

In the real system

The schema is one 2,347-line file: builder/server/internal/graph/model.go — "63 node types, 63 edge types, status enums, valid status transitions". The store is internal/graph/store.go: a neo4j.Driver + projectID, every query injecting $pid; CreateNode at store.go:175-210 is the idempotent MERGE. There's no ORM — hand-written Cypher constants, one method per use case. The real server pins driver v6; you'll use the v5 line, which is API-stable and works against Memgraph's Bolt.

  3. Write the store. Constructor connects over Bolt, verifies connectivity, and bakes in the project id. Context is always the first argument — the house rule (R4) you'll keep all course long:

    server/internal/graph/store.go
    package graph

import (
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"time"

	"github.com/neo4j/neo4j-go-driver/v5/neo4j"
)

var ErrNotFound = errors.New("node not found")
var ErrBadType = errors.New("unknown node type")

// Store carries the driver AND the project identity — callers can
// never forget project scoping because they never supply it.
type Store struct {
	driver    neo4j.DriverWithContext
	projectID string
}

func Open(ctx context.Context, boltURI, projectID string) (*Store, error) {
	driver, err := neo4j.NewDriverWithContext(boltURI, neo4j.NoAuth())
	if err != nil {
		return nil, fmt.Errorf("bolt_driver: %w", err)
	}
	if err := driver.VerifyConnectivity(ctx); err != nil {
		return nil, fmt.Errorf("memgraph_unreachable: is the container up? "+
			"(docker start memgraph): %w", err)
	}
	return &Store{driver: driver, projectID: projectID}, nil
}

func (s *Store) Close(ctx context.Context) error { return s.driver.Close(ctx) }

// run executes one Cypher statement with $pid always injected — the
// project-scoping-by-construction trick.
func (s *Store) run(ctx context.Context, cypher string,
	params map[string]any) (*neo4j.EagerResult, error) {
	if params == nil {
		params = map[string]any{}
	}
	params["pid"] = s.projectID
	return neo4j.ExecuteQuery(ctx, s.driver, cypher, params,
		neo4j.EagerResultTransformer)
}

// Fixed-width nanoseconds: lexicographic order IS time order, and
// "latest wins" reads (week 6) can't tie within a second.
func nowRFC3339() string {
	return time.Now().UTC().Format("2006-01-02T15:04:05.000000000Z07:00")
}

// serializeProps: anything non-scalar is JSON-stringified before
// storage. Memgraph could store nested maps natively — flattening is
// a CHOICE, not a protocol limit: it keeps every property greppable,
// string-comparable, and portable to Neo4j (whose properties really
// are scalars/flat lists only), exactly like the real server's
// serializeProps.
func serializeProps(in map[string]any) map[string]any {
	out := map[string]any{}
	for k, v := range in {
		switch v.(type) {
		case nil, bool, int, int64, float64, string:
			out[k] = v
		default:
			b, _ := json.Marshal(v)
			out[k] = string(b)
		}
	}
	return out
}

// CreateNode is an idempotent merge: insert on first sight, patch
// props on repeat — the retry-safe write agents depend on.
// Cypher cannot parameterize labels, so the label is interpolated —
// ONLY from the ValidNodeTypes allowlist (that check IS the injection
// guard, mirroring the real store's ValidateNeo4jIdentifier contract);
// values always travel as $parameters.
func (s *Store) CreateNode(ctx context.Context, n Node) error {
	if !ValidNodeTypes[n.Type] {
		return fmt.Errorf("%w: %q", ErrBadType, n.Type)
	}
	q := fmt.Sprintf(`
		MERGE (n:%s {id: $id, project_id: $pid})
		ON CREATE SET n += $props, n.status = $status,
		              n.created_at = $now, n.updated_at = $now
		ON MATCH SET  n += $props, n.updated_at = $now`, n.Type)
	_, err := s.run(ctx, q, map[string]any{
		"id": n.ID, "props": serializeProps(n.Props),
		"status": n.Status, "now": nowRFC3339(),
	})
	if err != nil {
		return fmt.Errorf("create node %s: %w", n.ID, err)
	}
	return nil
}

func (s *Store) GetNode(ctx context.Context, id string) (Node, error) {
	res, err := s.run(ctx, `
		MATCH (n {id: $id, project_id: $pid})
		RETURN labels(n)[0] AS type, n`, map[string]any{"id": id})
	if err != nil {
		return Node{}, fmt.Errorf("get node %s: %w", id, err)
	}
	if len(res.Records) == 0 {
		return Node{}, fmt.Errorf("%w: %s", ErrNotFound, id)
	}
	return nodeFromRecord(res.Records[0])
}

// nodeFromRecord splits bookkeeping fields out of the raw property
// bag; everything else is user props.
func nodeFromRecord(rec *neo4j.Record) (Node, error) {
	typ, _, _ := neo4j.GetRecordValue[string](rec, "type")
	raw, _, err := neo4j.GetRecordValue[neo4j.Node](rec, "n")
	if err != nil {
		return Node{}, fmt.Errorf("decode node: %w", err)
	}
	n := Node{Type: typ, Props: map[string]any{}}
	for k, v := range raw.Props {
		switch k {
		case "id":
			n.ID, _ = v.(string)
		case "status":
			n.Status, _ = v.(string)
		case "created_at":
			if s, ok := v.(string); ok {
				n.CreatedAt, _ = time.Parse(time.RFC3339, s)
			}
		case "updated_at":
			if s, ok := v.(string); ok {
				n.UpdatedAt, _ = time.Parse(time.RFC3339, s)
			}
		case "project_id": // bookkeeping, never surfaced
		default:
			n.Props[k] = v
		}
	}
	return n, nil
}

    Three patterns to notice, all lifted from the real store: sentinel errors wrapped with %w so callers use errors.Is; the allowlist-as-injection-guard for interpolated labels; and the MERGE write — Cypher's ON MATCH SET n += $props is the merge-don't-error semantics verbatim.

	"context"

func testStore(t *testing.T) (*Store, context.Context) {

func TestCreateNodeIsIdempotentMerge(t *testing.T) {
	s, ctx := testStore(t)
	n := Node{ID: "booking-core", Type: "Responsibility",
		Props: map[string]any{"name": "Booking core", "domain": "booking"}}
	if err := s.CreateNode(ctx, n); err != nil {
		t.Fatalf("first create: %v", err)
	}
	// Second create with new props must merge, not error.
	n.Props = map[string]any{"priority": "high"}
	if err := s.CreateNode(ctx, n); err != nil {
		t.Fatalf("second create: %v", err)
	}
	got, err := s.GetNode(ctx, "booking-core")
	if err != nil {
		t.Fatalf("get: %v", err)
	}
	if got.Props["name"] != "Booking core" || got.Props["priority"] != "high" {
		t.Fatalf("merge lost data: %+v", got.Props)
	}
}

1.3Edges make it a graphcreate_edge▶

Relationships in DDE are typed edges, never foreign-key properties. A WorkPackage points at its Responsibility with BELONGS_TO; a Finding points at what it affects with AFFECTS. This matters because everything downstream — the wave planner, the UI, context assembly — resolves relationships by walking edges. The real repo's rule is blunt: "properties like responsibility_id are NOT enough… if a dependency isn't an edge, it doesn't exist to the planner."

In the real system

.claude/rules/bld-graph-edge-contracts.md lists required edges per node type; the edge constants live at model.go:1008-1158 (~55 types). The PCC's GraphQL layer resolves every relationship via @relationship directives over these edges — a node created without its edges renders as an empty tab even though the data exists.

  2. Add edge writes and graph reads to the store:

    server/internal/graph/edges.go
    package graph

import (
	"context"
	"fmt"
)

// CreateEdge requires both endpoints to exist — an edge to a ghost
// node is how graphs silently rot. (A MATCH that finds nothing would
// no-op SILENTLY — that's why we existence-check first, loudly.)
func (s *Store) CreateEdge(ctx context.Context, src, dst, edgeType string) error {
	if !ValidEdgeTypes[edgeType] {
		return fmt.Errorf("unknown edge type %q", edgeType)
	}
	for _, id := range []string{src, dst} {
		if _, err := s.GetNode(ctx, id); err != nil {
			return fmt.Errorf("edge endpoint: %w", err)
		}
	}
	q := fmt.Sprintf(`
		MATCH (a {id: $src, project_id: $pid}),
		      (b {id: $dst, project_id: $pid})
		MERGE (a)-[:%s]->(b)`, edgeType)
	if _, err := s.run(ctx, q, map[string]any{"src": src, "dst": dst}); err != nil {
		return fmt.Errorf("create edge %s-[%s]->%s: %w", src, edgeType, dst, err)
	}
	return nil
}

// QueryAll lists nodes of a type, optionally filtered by status.
func (s *Store) QueryAll(ctx context.Context, nodeType, status string) ([]Node, error) {
	if !ValidNodeTypes[nodeType] {
		return nil, fmt.Errorf("%w: %q", ErrBadType, nodeType)
	}
	q := fmt.Sprintf(`
		MATCH (n:%s {project_id: $pid})
		WHERE $status = '' OR n.status = $status
		RETURN labels(n)[0] AS type, n
		ORDER BY n.id`, nodeType)
	res, err := s.run(ctx, q, map[string]any{"status": status})
	if err != nil {
		return nil, fmt.Errorf("query %s: %w", nodeType, err)
	}
	var out []Node
	for _, rec := range res.Records {
		n, err := nodeFromRecord(rec)
		if err != nil {
			return nil, err
		}
		out = append(out, n)
	}
	return out, nil
}

// Neighbors walks one hop. dir is "out" (edges leaving id) or "in"
// (edges arriving at id); edgeType "" means any.
func (s *Store) Neighbors(ctx context.Context, id, dir, edgeType string) ([]Edge, error) {
	q := `MATCH (a {id: $id, project_id: $pid})-[r]->(b)
	      WHERE ($t = '' OR type(r) = $t) AND b.project_id = $pid
	      RETURN a.id AS src, b.id AS dst, type(r) AS type`
	if dir == "in" {
		q = `MATCH (b)-[r]->(a {id: $id, project_id: $pid})
		     WHERE ($t = '' OR type(r) = $t) AND b.project_id = $pid
		     RETURN b.id AS src, a.id AS dst, type(r) AS type`
	}
	res, err := s.run(ctx, q, map[string]any{"id": id, "t": edgeType})
	if err != nil {
		return nil, fmt.Errorf("neighbors of %s: %w", id, err)
	}
	var out []Edge
	for _, rec := range res.Records {
		var e Edge
		e.Src, _, _ = neo4j.GetRecordValue[string](rec, "src")
		e.Dst, _, _ = neo4j.GetRecordValue[string](rec, "dst")
		e.Type, _, _ = neo4j.GetRecordValue[string](rec, "type")
		out = append(out, e)
	}
	return out, nil
}

// DeleteNode: DETACH DELETE — the rollback primitive weeks 2-3 use
// when a bundled write half-fails.
func (s *Store) DeleteNode(ctx context.Context, id string) error {
	_, err := s.run(ctx, `MATCH (n {id: $id, project_id: $pid}) DETACH DELETE n`,
		map[string]any{"id": id})
	return err
}

1.4A CLI to talk to itoperator surface▶

Before agents get an MCP surface (week 4), you need a surface. A small CLI over the store does double duty: it's your debugging tool for the whole course, and it forces the store's API to be usable by something other than tests. Output is JSON — the graph's lingua franca.

In the real system

The real server's entrypoint (builder/server/main.go) serves stdio MCP and HTTP; operators also drive it through the PCC and a CLI package (internal/cli). The habit you're building — "ask the graph, get JSON" — is the graph-first discipline of .claude/rules/bld-knowledge-graph-first.md.

Tasks

  1. Write the entrypoint with stdlib flag subcommands (no framework):

    server/cmd/minidde/main.go
    package main

import (
	"context"
	"encoding/json"
	"flag"
	"fmt"
	"os"

	"minidde/server/internal/graph"
)

func main() {
	if err := run(os.Args[1:]); err != nil {
		fmt.Fprintln(os.Stderr, "error:", err)
		os.Exit(1)
	}
}

func openStore(ctx context.Context) (*graph.Store, error) {
	// Course simplification for week 1: env with the same defaults
	// .minidde/project.yaml pins. Week 4 replaces this with a real
	// config loader reading that file.
	pid := os.Getenv("MINIDDE_PROJECT")
	if pid == "" {
		pid = "mini-c2c"
	}
	uri := os.Getenv("MINIDDE_BOLT")
	if uri == "" {
		uri = "bolt://localhost:7687"
	}
	return graph.Open(ctx, uri, pid)
}

func emit(v any) error {
	enc := json.NewEncoder(os.Stdout)
	enc.SetIndent("", "  ")
	return enc.Encode(v)
}

func run(args []string) error {
	if len(args) == 0 {
		return fmt.Errorf("usage: minidde <create-node|get|ls|link|neighbors> ...")
	}
	ctx := context.Background()
	s, err := openStore(ctx)
	if err != nil {
		return err
	}
	defer s.Close(ctx)

	switch args[0] {
	case "create-node":
		fs := flag.NewFlagSet("create-node", flag.ExitOnError)
		id := fs.String("id", "", "node id")
		typ := fs.String("type", "", "node type")
		props := fs.String("props", "{}", "JSON properties")
		fs.Parse(args[1:])
		var p map[string]any
		if err := json.Unmarshal([]byte(*props), &p); err != nil {
			return fmt.Errorf("bad --props: %w", err)
		}
		if err := s.CreateNode(ctx, graph.Node{ID: *id, Type: *typ, Props: p}); err != nil {
			return err
		}
		n, _ := s.GetNode(ctx, *id)
		return emit(n)
	case "get":
		n, err := s.GetNode(ctx, args[1])
		if err != nil {
			return err
		}
		return emit(n)
	case "ls":
		fs := flag.NewFlagSet("ls", flag.ExitOnError)
		typ := fs.String("type", "Responsibility", "node type")
		status := fs.String("status", "", "status filter")
		fs.Parse(args[1:])
		nodes, err := s.QueryAll(ctx, *typ, *status)
		if err != nil {
			return err
		}
		return emit(nodes)
	case "link":
		fs := flag.NewFlagSet("link", flag.ExitOnError)
		src := fs.String("src", "", "source node id")
		dst := fs.String("dst", "", "target node id")
		typ := fs.String("type", "", "edge type")
		fs.Parse(args[1:])
		if err := s.CreateEdge(ctx, *src, *dst, *typ); err != nil {
			return err
		}
		return emit(map[string]string{"created": *src + " -[" + *typ + "]-> " + *dst})
	case "neighbors":
		fs := flag.NewFlagSet("neighbors", flag.ExitOnError)
		id := fs.String("id", "", "node id")
		dir := fs.String("dir", "out", "out|in")
		typ := fs.String("type", "", "edge type filter")
		fs.Parse(args[1:])
		edges, err := s.Neighbors(ctx, *id, *dir, *typ)
		if err != nil {
			return err
		}
		return emit(edges)
	default:
		return fmt.Errorf("unknown command %q", args[0])
	}
}
