1.1The four planes of DDE — orientation & setupworldview▶

Nexus DDE ("Decision-Driven Engineering") is not one tool — it's four planes that stay deliberately separate. Intent lives in decision records (xDRs) on disk. Context lives in always-loaded rules that put constraints in every agent session. Mechanism lives in hooks, lints, and gates that block bad writes. State lives in the knowledge graph, which every agent queries before touching files. Confusing the planes is the root failure DDE prevents: a rule without a decision record is authority from nowhere; a decision without enforcement is a wish; state kept in prose is state nobody can query.

In the real system

docs/governance-framework.md §1 draws the four-plane diagram; CLAUDE.md § "Knowledge graph (single source of truth)" mandates graph-before-files; the hosted graph is reached via the dde MCP server (110 tools, Neo4j behind it). The one-way hierarchy — xDR → .claude/rules/ → enforcement — is formalized in ADR-ono-xdrs-source-ESHJ: implementation layers cite the decision they implement and never author authority themselves.

1.2A node store in ~150 linescreate_node▶

A graph node in DDE is deliberately generic: an id, a type (Responsibility, Finding, Decision…), a status, and a bag of properties. The store bakes the project_id in at construction so no caller can forget it, and writes are idempotent merges: creating a node that exists updates its properties instead of erroring — the same MERGE … ON CREATE SET n = $props ON MATCH SET n += $props semantics the real server runs in Cypher, which is what lets agents safely retry.

In the real system

The schema is one 2,347-line file: builder/server/internal/graph/model.go — "63 node types, 63 edge types, status enums, valid status transitions". The store is internal/graph/store.go: a neo4j.Driver + projectID, every query injecting $pid; CreateNode at store.go:175-210 is the idempotent MERGE. There's no ORM — hand-written Cypher constants, one method per use case.

  3. Write the store. Constructor opens the DB, applies the schema, and bakes in the project id:

    server/internal/graph/store.go
    package graph

import (
	"database/sql"
	"encoding/json"
	"errors"
	"fmt"
	"time"

	_ "modernc.org/sqlite"
)

var ErrNotFound = errors.New("node not found")
var ErrBadType = errors.New("unknown node type")

const schema = `
CREATE TABLE IF NOT EXISTS nodes (
  id         TEXT NOT NULL,
  project_id TEXT NOT NULL,
  type       TEXT NOT NULL,
  status     TEXT NOT NULL DEFAULT '',
  props      TEXT NOT NULL DEFAULT '{}',
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  PRIMARY KEY (id, project_id)
);
CREATE INDEX IF NOT EXISTS idx_nodes_type ON nodes(project_id, type);
CREATE TABLE IF NOT EXISTS edges (
  project_id TEXT NOT NULL,
  src TEXT NOT NULL, dst TEXT NOT NULL, type TEXT NOT NULL,
  created_at TEXT NOT NULL,
  PRIMARY KEY (project_id, src, dst, type)
);`

// Store carries the connection AND the project identity — callers can
// never forget project scoping because they never supply it.
type Store struct {
	db        *sql.DB
	projectID string
}

func Open(path, projectID string) (*Store, error) {
	db, err := sql.Open("sqlite", path)
	if err != nil {
		return nil, fmt.Errorf("open %s: %w", path, err)
	}
	if _, err := db.Exec(schema); err != nil {
		return nil, fmt.Errorf("apply schema: %w", err)
	}
	return &Store{db: db, projectID: projectID}, nil
}

func (s *Store) Close() error { return s.db.Close() }

// CreateNode is an idempotent merge: insert on first sight, patch
// props on repeat — the retry-safe write agents depend on.
func (s *Store) CreateNode(n Node) error {
	if !ValidNodeTypes[n.Type] {
		return fmt.Errorf("%w: %q", ErrBadType, n.Type)
	}
	props, err := json.Marshal(n.Props)
	if err != nil {
		return fmt.Errorf("marshal props: %w", err)
	}
	now := time.Now().UTC().Format(time.RFC3339)
	_, err = s.db.Exec(`
		INSERT INTO nodes (id, project_id, type, status, props, created_at, updated_at)
		VALUES (?, ?, ?, ?, ?, ?, ?)
		ON CONFLICT(id, project_id) DO UPDATE SET
		  props = json_patch(nodes.props, excluded.props),
		  updated_at = excluded.updated_at`,
		n.ID, s.projectID, n.Type, n.Status, string(props), now, now)
	if err != nil {
		return fmt.Errorf("create node %s: %w", n.ID, err)
	}
	return nil
}

func (s *Store) GetNode(id string) (Node, error) {
	var n Node
	var props, created, updated string
	err := s.db.QueryRow(`
		SELECT id, type, status, props, created_at, updated_at
		FROM nodes WHERE id = ? AND project_id = ?`,
		id, s.projectID).Scan(&n.ID, &n.Type, &n.Status, &props, &created, &updated)
	if errors.Is(err, sql.ErrNoRows) {
		return n, fmt.Errorf("%w: %s", ErrNotFound, id)
	}
	if err != nil {
		return n, fmt.Errorf("get node %s: %w", id, err)
	}
	_ = json.Unmarshal([]byte(props), &n.Props)
	n.CreatedAt, _ = time.Parse(time.RFC3339, created)
	n.UpdatedAt, _ = time.Parse(time.RFC3339, updated)
	return n, nil
}

    Two patterns to notice, both lifted from the real store: sentinel errors wrapped with %w so callers use errors.Is, and the merge-on-conflict write (SQLite's json_patch plays the role of Cypher's n += $props).

1.3Edges make it a graphcreate_edge▶

Relationships in DDE are typed edges, never foreign-key properties. A WorkPackage points at its Responsibility with BELONGS_TO; a Finding points at what it affects with AFFECTS. This matters because everything downstream — the wave planner, the UI, context assembly — resolves relationships by walking edges. The real repo's rule is blunt: "properties like responsibility_id are NOT enough… if a dependency isn't an edge, it doesn't exist to the planner."

In the real system

.claude/rules/bld-graph-edge-contracts.md lists required edges per node type; the edge constants live at model.go:1008-1158 (~55 types). The PCC's GraphQL layer resolves every relationship via @relationship directives over these edges — a node created without its edges renders as an empty tab even though the data exists.

    server/internal/graph/edges.go
    package graph

import (
	"fmt"
	"time"
)

// CreateEdge requires both endpoints to exist — an edge to a ghost
// node is how graphs silently rot.
func (s *Store) CreateEdge(src, dst, edgeType string) error {
	if !ValidEdgeTypes[edgeType] {
		return fmt.Errorf("unknown edge type %q", edgeType)
	}
	for _, id := range []string{src, dst} {
		if _, err := s.GetNode(id); err != nil {
			return fmt.Errorf("edge endpoint: %w", err)
		}
	}
	now := time.Now().UTC().Format(time.RFC3339)
	_, err := s.db.Exec(`
		INSERT INTO edges (project_id, src, dst, type, created_at)
		VALUES (?, ?, ?, ?, ?)
		ON CONFLICT DO NOTHING`,
		s.projectID, src, dst, edgeType, now)
	if err != nil {
		return fmt.Errorf("create edge %s-[%s]->%s: %w", src, edgeType, dst, err)
	}
	return nil
}

// QueryAll lists nodes of a type, optionally filtered by status.
func (s *Store) QueryAll(nodeType, status string) ([]Node, error) {
	q := `SELECT id FROM nodes WHERE project_id = ? AND type = ?`
	args := []any{s.projectID, nodeType}
	if status != "" {
		q += ` AND status = ?`
		args = append(args, status)
	}
	q += ` ORDER BY id`
	rows, err := s.db.Query(q, args...)
	if err != nil {
		return nil, fmt.Errorf("query %s: %w", nodeType, err)
	}
	defer rows.Close()
	var out []Node
	for rows.Next() {
		var id string
		if err := rows.Scan(&id); err != nil {
			return nil, err
		}
		n, err := s.GetNode(id)
		if err != nil {
			return nil, err
		}
		out = append(out, n)
	}
	return out, rows.Err()
}

// Neighbors walks one hop. dir is "out" (src=id) or "in" (dst=id);
// edgeType "" means any.
func (s *Store) Neighbors(id, dir, edgeType string) ([]Edge, error) {
	col := "src"
	if dir == "in" {
		col = "dst"
	}
	q := fmt.Sprintf(`SELECT src, dst, type FROM edges
		WHERE project_id = ? AND %s = ?`, col)
	args := []any{s.projectID, id}
	if edgeType != "" {
		q += ` AND type = ?`
		args = append(args, edgeType)
	}
	rows, err := s.db.Query(q, args...)
	if err != nil {
		return nil, fmt.Errorf("neighbors of %s: %w", id, err)
	}
	defer rows.Close()
	var out []Edge
	for rows.Next() {
		var e Edge
		if err := rows.Scan(&e.Src, &e.Dst, &e.Type); err != nil {
			return nil, err
		}
		out = append(out, e)
	}
	return out, rows.Err()
}

func openStore() (*graph.Store, error) {
	// Course simplification: project id from env with the same
	// default the .minidde/project.yaml pins.

		db = "minidde.db"

func emit(v any) error {
	enc := json.NewEncoder(os.Stdout)
	enc.SetIndent("", "  ")
	return enc.Encode(v)
}

		id := fs.String("id", "", "node id")

2.1Status is a state machineupdate_status▶

Every tracked node type carries a transition map — the complete list of legal from→to moves. There is exactly one legitimate status writer, update_status, which validates the transition, demands a reason, records a changelog entry, and rejects same-status writes. Setting status through a generic property update is forbidden — that's the difference between a lifecycle and a text field.

In the real system

2.2Content-addressed IDsallocator▶

Decision records get IDs like ADR-outcome-graph-primitive-MHMV: a type, a slug derived from the title, and a random 4-char suffix. Never sequential. Sequential numbering needs a central counter, and the moment two agent sessions author records in parallel branches, counters collide. Content-addressed IDs are allocated server-side, atomically, and a record's identity never depends on authoring order.

In the real system

DeriveSlug lives in builder/server/internal/graph/decision_id.go: lowercase, stop-words removed, max 3 meaningful words, max 32 chars. Suffixes are crypto/rand Crockford base32 — alphabet 0123456789ABCDEFGHJKMNPQRSTVWXYZ, no I/L/O/U, for speakability. Allocate (allocator.go:86-110) retries 8 candidates at width 4, widening to 5 then 6, each attempt one atomic statement. Governance is Builder ADR-atomic-id-allocator-H37G; the caller-supplied-ID ban is ADR-id-canonicalization-server-ZRZ5 — "server allocates, disk follows".

    server/internal/graph/allocator.go
    package graph

import (
	"crypto/rand"
	"fmt"
	"regexp"
	"strings"
)

// Crockford base32 minus the confusable letters I, L, O, U.
const suffixAlphabet = "0123456789ABCDEFGHJKMNPQRSTVWXYZ"

var stopWords = map[string]bool{
	"a": true, "the": true, "for": true, "of": true, "in": true,
	"to": true, "and": true, "with": true, "on": true, "at": true,
}
var nonAlnum = regexp.MustCompile(`[^a-z0-9]+`)

// DeriveSlug: lowercase, drop stop-words, keep at most 3 meaningful
// words, cap at 32 chars on a word boundary, kebab-case.
func DeriveSlug(title string) string {
	words := nonAlnum.Split(strings.ToLower(title), -1)
	var kept []string
	for _, w := range words {
		if w == "" || stopWords[w] {
			continue
		}
		kept = append(kept, w)
		if len(kept) == 3 {
			break
		}
	}
	slug := strings.Join(kept, "-")
	for len(slug) > 32 {
		if i := strings.LastIndex(slug, "-"); i > 0 {
			slug = slug[:i]
		} else {
			slug = slug[:32]
		}
	}
	if slug == "" {
		slug = "record"
	}
	return slug
}

func GenerateSuffix(width int) (string, error) {
	b := make([]byte, width)
	if _, err := rand.Read(b); err != nil {
		return "", fmt.Errorf("entropy: %w", err)
	}
	out := make([]byte, width)
	for i, v := range b {
		out[i] = suffixAlphabet[int(v)%len(suffixAlphabet)]
	}
	return string(out), nil
}

    server/internal/graph/allocator.go (append)
    // AllocateDecisionID mints a canonical id: TYPE-slug-XXXX. Uniqueness
// rides the (id, project_id) primary key — INSERT wins or collides,
// there is no read-then-write race.
func (s *Store) AllocateDecisionID(docType, title string) (string, error) {
	dt := strings.ToUpper(docType) // ADR | PDR | DDR | WOW | CIR
	slug := DeriveSlug(title)
	for width := 4; width <= 6; width++ {
		for attempt := 0; attempt < 8; attempt++ {
			sfx, err := GenerateSuffix(width)
			if err != nil {
				return "", err
			}
			id := fmt.Sprintf("%s-%s-%s", dt, slug, sfx)
			res, err := s.db.Exec(`
				INSERT INTO nodes (id, project_id, type, status, props, created_at, updated_at)
				VALUES (?, ?, 'Decision', 'Proposed', '{}',
				        strftime('%Y-%m-%dT%H:%M:%SZ','now'),
				        strftime('%Y-%m-%dT%H:%M:%SZ','now'))
				ON CONFLICT DO NOTHING`, id, s.projectID)
			if err != nil {
				return "", fmt.Errorf("allocate: %w", err)
			}
			if n, _ := res.RowsAffected(); n == 1 {
				return id, nil // we created it — the id is ours
			}
			// collision: re-roll
		}
	}
	return "", fmt.Errorf("retry_exhausted: could not allocate id for %q", title)
}

2.3Edge contracts & server-minted edgesrequired edges▶

Some edges aren't optional decoration — they're part of what makes a node valid. In the real system a new Responsibility must carry at least one lineage edge (where did this work come from — a CIR? a Decision? a Finding?) in the same create call, and each lineage target must already exist. The deeper principle: required edges are created inside the write, never left to a second client call that might never come.

In the real system

ValidLineageEdges = {ORIGINATED_FROM, GOVERNED_BY, SPAWNED_FROM, DERIVED_FROM} (model.go:1162-1167); ≥1 required per new Responsibility, targets existence-checked before persist (create_node.go:415-440). register_finding goes further: it writes the Finding, mints AFFECTS/FOUND_IN, then re-reads the edges and rolls the whole Finding back if they failed to land — a rolled-back finding is never embedded, changelogged, or notified.

import "fmt"

var lineageEdges = map[string]bool{

	"SPAWNED_FROM": true, "DERIVED_FROM": true,

	Src, Dst, Type string
}

// CreateNodeWithEdges enforces per-type edge contracts, then writes
// node + edges together. Responsibility: ≥1 lineage edge whose target
// already exists.
func (s *Store) CreateNodeWithEdges(n Node, edges []BundledEdge) error {
	if n.Type == "Responsibility" {
		hasLineage := false
		for _, e := range edges {
			if lineageEdges[e.Type] {
				if _, err := s.GetNode(e.Dst); err != nil {
					return fmt.Errorf("lineage_target_missing: %s: %w", e.Dst, err)
				}

			}

			return fmt.Errorf("bundled_edge_failed (node rolled back): %w", err)
		}
	}
	return nil

2.4Validators at the boundaryvalidator chains▶

Validation in DDE is not scattered if statements — it's ordered chains of named validators run at the write boundary, each returning either a structured rejection or nil. Two conventions make the pattern scale: errors lead with a machine-parseable code (lineage_required: … — you've been doing this since 2.1 without noticing), and every covered node type gets a plain-English eli10 summary so the graph stays legible to humans.

In the real system

update_node.go:188-220 runs a 14-validator chain — the load-bearing one rejects any status key with "use update_status instead". validate_eli10.go checks: 80–350 bytes, single paragraph, no code fences, ≤2 inline-code spans, unexpanded acronyms only from a 23-entry allowlist. Presence is enforced when ELI10_ENFORCE=1; malformed values are always rejected. Errors follow the three-tier contract: ToolError with a leading code, sentinel errors, pinned JSON-RPC codes.

    scripts/lint-decisions.sh
    #!/usr/bin/env bash
# Mini governance lint: filename shape, meta block, required sections,
# supersession symmetry. Exit 1 on any FAIL.
set -uo pipefail
fails=0
fail() { echo "FAIL  $1: $2"; fails=$((fails+1)); }
pass() { echo "PASS  $1"; }

shopt -s nullglob
for f in docs/{adr,pdr,ddr,wow,cir}/*.md; do
  base=$(basename "$f")
  [[ "$base" == 000-template.md ]] && continue

  # 1. filename: <type>-<slug>-<XXXX>.md, suffix Crockford (no i,l,o,u)
  if [[ ! "$base" =~ ^(adr|pdr|ddr|wow|cir)-[a-z0-9-]+-[0-9A-HJKMNP-TV-Z]{4}\.md$ ]]; then
    fail "$base" "filename must be <type>-<slug>-<XXXX>.md"
    continue
  fi

  # 2. meta block: id matches filename, status is a legal value
  id_in_file=$(grep -o '<id>[^<]*</id>' "$f" | sed 's/<[^>]*>//g')
  want_id=$(echo "${base%.md}" | awk -F- '{printf toupper($1); for(i=2;i<=NF;i++) printf "-"$i}')
  [[ "$id_in_file" == "$want_id" ]] || fail "$base" "meta id '$id_in_file' != filename id '$want_id'"
  status=$(grep -o '<status>[^<]*</status>' "$f" | sed 's/<[^>]*>//g')
  case "$status" in Proposed|Accepted|Superseded|Deprecated) ;; *)
    fail "$base" "illegal status '$status'";; esac

  # 3. required sections
  for sec in "## Context" "## Decision" "## Consequences" "## Compliance"; do
    grep -q "^$sec" "$f" || fail "$base" "missing section '$sec'"
  done

  # 4. compliance heuristic: >=30 chars of substance
  comp=$(awk '/^## Compliance/{flag=1;next}/^## /{flag=0}flag' "$f" | tr -d ' \n')
  [[ ${#comp} -ge 30 ]] || fail "$base" "Compliance section too thin (<30 chars)"

  # 5. supersession symmetry: if I supersede X, X must name me back
  sup=$(grep -o '<supersedes>[^<]*</supersedes>' "$f" | sed 's/<[^>]*>//g')
  if [[ -n "$sup" ]]; then
    lower=$(echo "$sup" | tr 'A-Z' 'a-z')
    old="docs/${lower%%-*}/${lower}.md"
    if [[ ! -f "$old" ]]; then fail "$base" "supersedes '$sup' but $old not found"
    elif ! grep -q "<superseded-by>$want_id</superseded-by>" "$old"; then
      fail "$base" "$old does not point back via <superseded-by>"
    fi
  fi
  pass "$base"
done
echo; echo "$fails failure(s)"
exit $((fails > 0))

3.4Findings & escalationsregister_finding▶

A Finding is the graph's unit of "something is wrong or unknown": a defect, a gap, an ambiguity, discovered mid-work. It has a hard field contract (thin findings are noise), required edges to what it affects, and a lifecycle that ends only in CONFIRMED, REJECTED, or DEFERRED. An Escalation is a question for the decision authority with explicit options. Together they implement the agent doctrine: confusion that is not surfaced becomes fabrication.

In the real system

register_finding enforces: title ≥10, description ≥50, evidence ≥30, recommendation ≥30 chars, severity enum, required classification (19-value taxonomy), server-allocated id, AFFECTS/FOUND_IN edges with a verify-and-rollback gate. resolve_finding: OPEN→RESOLVED only, resolution ≥50 chars, verification_note ≥30. reject_finding: DA only. Escalations: register_escalation with options; resolve_escalation refuses unless status is exactly pending — the lifecycle is tool-owned, no transition map to game.

func (s *Store) RegisterEscalation(question string, options []string, eli10 string) (string, error) {
	if question == "" || len(options) < 2 {

// the lifecycle is owned by this function, not a transition map.
func (s *Store) ResolveEscalation(id, chosen, resolvedBy string) error {
	n, err := s.GetNode(id)
	if err != nil {
		return err
	}
	if n.Status != "pending" {
		return fmt.Errorf("escalation_not_pending: %s is %q", id, n.Status)
	}

		"resolution": chosen, "resolved_by": resolvedBy,
	}); err != nil {
		return err
	}
	return s.UpdateStatus(id, "resolved", "DA chose: "+chosen)
}

// ValidateAgainst compiles a JSON Schema (given as a string) and
// validates a payload, returning per-path errors — real Draft
// validation, not field-name eyeballing.
func ValidateAgainst(schemaJSON string, payload []byte) (bool, []SchemaError, error) {
	var doc any
	if err := json.Unmarshal([]byte(schemaJSON), &doc); err != nil {
		return false, nil, fmt.Errorf("schema_invalid_json: %w", err)
	}
	c := jsonschema.NewCompiler()
	if err := c.AddResource("mem://contract.json", doc); err != nil {
		return false, nil, fmt.Errorf("schema_add: %w", err)
	}
	sch, err := c.Compile("mem://contract.json")
	if err != nil {
		return false, nil, fmt.Errorf("schema_compile: %w", err)
	}
	var inst any
	if err := json.Unmarshal(payload, &inst); err != nil {
		return false, nil, fmt.Errorf("payload_invalid_json: %w", err)
	}
	if err := sch.Validate(inst); err != nil {
		var out []SchemaError
		if ve, ok := err.(*jsonschema.ValidationError); ok {
			for _, cause := range ve.Causes {
				out = append(out, SchemaError{
					Path:    "/" + strings.Join(anyToStrings(cause.InstanceLocation), "/"),
					Message: cause.ErrorKind.LocalizedString(nil),
				})
			}
			if len(out) == 0 {
				out = append(out, SchemaError{Path: "/", Message: ve.Error()})
			}
		} else {
			out = append(out, SchemaError{Path: "/", Message: err.Error()})
		}
		return false, out, nil
	}
	return true, nil, nil
}

5.2Choreography is the dependency modelPRODUCES / CONSUMES▶

Nowhere in DDE does anyone declare "billing depends on booking." Dependency is derived from event choreography: if booking PRODUCES an event that billing CONSUMES, billing depends on booking — full stop. The consequence cuts both ways: model the edges and the planner sees the truth; forget an edge and the dependency does not exist to any downstream machinery.

In the real system

The planner's Cypher reads exactly one pattern: (producer)-[:PRODUCES]->(e:Event)<-[:CONSUMES]-(consumer) (wave.go:167-169). Each pair becomes one WP-level edge: the consumer's first WP depends on the producer's last WP — the coarsest ordering that guarantees the producer is fully built first. Even infrastructure enters the ordering only as CONSUMES edges on capability events (.claude/rules/bld-graph-maintenance.md).

    package graph

import "sort"

// wpsOf returns a responsibility's WorkPackages ordered by sequence
// (id tie-break) — determinism matters: identical graphs must yield
// identical plans.
func (s *Store) wpsOf(respID string) ([]Node, error) {
	edges, err := s.Neighbors(respID, "in", EdgeBelongsTo)
	if err != nil {
		return nil, err
	}
	var wps []Node
	for _, e := range edges {
		n, err := s.GetNode(e.Src)
		if err != nil {
			return nil, err
		}
		wps = append(wps, n)
	}
	sort.Slice(wps, func(i, j int) bool {
		si, _ := wps[i].Props["sequence"].(float64)
		sj, _ := wps[j].Props["sequence"].(float64)
		if si != sj {
			return si < sj
		}
		return wps[i].ID < wps[j].ID
	})
	return wps, nil
}

// ChoreographyDeps derives WP→WP dependencies from PRODUCES/CONSUMES:
// for each event, each consumer's FIRST wp depends on each producer's
// LAST wp.
func (s *Store) ChoreographyDeps() (map[string][]string, error) {
	deps := map[string][]string{} // wp → the wps it depends on
	events, err := s.QueryAll("Event", "")
	if err != nil {
		return nil, err
	}
	for _, evt := range events {
		producers, err := s.Neighbors(evt.ID, "in", EdgeProduces)
		if err != nil {
			return nil, err
		}
		consumers, err := s.Neighbors(evt.ID, "in", EdgeConsumes)
		if err != nil {
			return nil, err
		}
		for _, c := range consumers {
			for _, p := range producers {
				if c.Src == p.Src {
					continue // self-loops never count
				}
				pWPs, err := s.wpsOf(p.Src)
				if err != nil {
					return nil, err
				}
				cWPs, err := s.wpsOf(c.Src)
				if err != nil {
					return nil, err
				}
				if len(pWPs) == 0 || len(cWPs) == 0 {
					continue
				}
				first, last := cWPs[0].ID, pWPs[len(pWPs)-1].ID
				deps[first] = append(deps[first], last)
			}
		}
	}
	return deps, nil
}

5.3The wave plannercompute_wave_plan▶

A wave is a set of work packages whose dependencies are all satisfied by earlier waves — the parallel-execution unit for dispatching builders. The planner merges three dependency sources (explicit DEPENDS_ON edges, derived choreography, implicit within-responsibility sequence), then runs Kahn's algorithm. The design decision worth tattooing somewhere: on a cycle, it persists nothing and fails loudly, naming the members — a silently-persisted cyclic plan yields zero claimable work packages and looks like success.

In the real system

wave.go:32-76: load WPs → adjacency from explicit + choreography + sequential (a sequential edge that would close a cycle is skipped via a reachability check) → Kahn with sorted queues for determinism → wave = max(dep waves) + 1 → cycle members reported, nothing persisted (compute_wave_plan.go:31-39). Persisted derived edges are tagged computed_by = "compute_wave_plan" and excluded from the next run's input — a planner must never eat its own output.

  1. Implement the planner:

    server/internal/graph/wave.go
    package graph

import (
	"fmt"
	"sort"
)

type Wave struct {
	Number       int      `json:"number"`
	WorkPackages []string `json:"work_packages"`
}

type WavePlan struct {
	Waves          []Wave   `json:"waves"`
	TotalWaves     int      `json:"total_waves"`
	MaxParallelism int      `json:"max_parallelism"`
	Cycles         []string `json:"cycles,omitempty"`
}

func (s *Store) ComputeWavePlan() (WavePlan, error) {
	wps, err := s.QueryAll("WorkPackage", "")
	if err != nil {
		return WavePlan{}, err
	}
	deps := map[string]map[string]bool{} // wp → set of wps it depends on
	add := func(wp, dep string) {
		if deps[wp] == nil {
			deps[wp] = map[string]bool{}
		}
		deps[wp][dep] = true
	}
	for _, wp := range wps {
		deps[wp.ID] = deps[wp.ID] // ensure key exists
	}

	// Source 1: explicit DEPENDS_ON edges.
	for _, wp := range wps {
		out, err := s.Neighbors(wp.ID, "out", EdgeDependsOn)
		if err != nil {
			return WavePlan{}, err
		}
		for _, e := range out {
			add(wp.ID, e.Dst)
		}
	}
	// Source 2: choreography (lesson 5.2).
	choreo, err := s.ChoreographyDeps()
	if err != nil {
		return WavePlan{}, err
	}
	for wp, ds := range choreo {
		for _, d := range ds {
			add(wp, d)
		}
	}
	// Source 3: implicit sequence within each Responsibility.
	resps, err := s.QueryAll("Responsibility", "")
	if err != nil {
		return WavePlan{}, err
	}
	for _, r := range resps {
		seq, err := s.wpsOf(r.ID)
		if err != nil {
			return WavePlan{}, err
		}
		for i := 1; i < len(seq); i++ {
			add(seq[i].ID, seq[i-1].ID)
		}
	}

	// Kahn's algorithm with sorted queues for determinism.
	wave := map[string]int{}
	remaining := map[string]map[string]bool{}
	for wp, ds := range deps {
		remaining[wp] = map[string]bool{}
		for d := range ds {
			remaining[wp][d] = true
		}
	}
	for {
		var ready []string
		for wp, ds := range remaining {
			if len(ds) == 0 {
				ready = append(ready, wp)
			}
		}
		if len(ready) == 0 {
			break
		}
		sort.Strings(ready)
		for _, wp := range ready {
			w := 1
			for d := range deps[wp] {
				if dw, ok := wave[d]; ok && dw >= w {
					w = dw + 1
				}
			}
			wave[wp] = w
			delete(remaining, wp)
			for _, ds := range remaining {
				delete(ds, wp)
			}
		}
	}

	// Anything left is a cycle member: REFUSE, persist nothing.
	if len(remaining) > 0 {
		var members []string
		for wp := range remaining {
			members = append(members, wp)
		}
		sort.Strings(members)
		return WavePlan{Cycles: members},
			fmt.Errorf("dependency_cycle: %v — fix the graph; an unaddressed "+
				"cycle leaves zero claimable work packages", members)
	}

	// Persist wave numbers; assemble the plan.
	byWave := map[int][]string{}
	maxW, maxPar := 0, 0
	for wp, w := range wave {
		byWave[w] = append(byWave[w], wp)
		if w > maxW {
			maxW = w
		}
	}
	var plan WavePlan
	for w := 1; w <= maxW; w++ {
		sort.Strings(byWave[w])
		if len(byWave[w]) > maxPar {
			maxPar = len(byWave[w])
		}
		plan.Waves = append(plan.Waves, Wave{Number: w, WorkPackages: byWave[w]})
		for _, wp := range byWave[w] {
			s.UpdateNode(wp, map[string]any{"wave": w})
		}
	}
	plan.TotalWaves, plan.MaxParallelism = maxW, maxPar
	return plan, nil
}

  1. Define the package and assemble it:

    server/internal/graph/context.go
    package graph

import "os"

type ContextPackage struct {
	Responsibility Node   `json:"responsibility"`
	Specification  string `json:"specification"`
	EventsConsumed []Node `json:"events_consumed"`
	EventsProduced []Node `json:"events_produced"`
	Decisions      []Node `json:"decisions"`
	OpenFindings   []Node `json:"open_findings"`
	WorkPackages   []Node `json:"work_packages"`
}

func (s *Store) AssembleContext(respID string) (ContextPackage, error) {
	var pkg ContextPackage
	resp, err := s.GetNode(respID)
	if err != nil {
		return pkg, err
	}
	pkg.Responsibility = resp

	// Specification: follow DOCUMENTED_BY to a Document, read its
	// path from disk — the one intentional full-text copy.
	docs, _ := s.Neighbors(respID, "out", EdgeDocumentedBy)
	for _, e := range docs {
		d, err := s.GetNode(e.Dst)
		if err != nil {
			continue
		}
		if path, ok := d.Props["path"].(string); ok {
			if body, err := os.ReadFile(path); err == nil {
				pkg.Specification = string(body)
				break
			}
		}
	}

	collect := func(dir, edgeType string) []Node {
		var out []Node
		edges, _ := s.Neighbors(respID, dir, edgeType)
		for _, e := range edges {
			other := e.Dst
			if dir == "in" {
				other = e.Src
			}
			if n, err := s.GetNode(other); err == nil {
				out = append(out, n)
			}
		}
		return out
	}
	pkg.EventsConsumed = collect("out", EdgeConsumes)
	pkg.EventsProduced = collect("out", EdgeProduces)
	pkg.Decisions = collect("out", EdgeGovernedBy)
	pkg.WorkPackages = collect("in", EdgeBelongsTo)
	for _, f := range collect("in", EdgeAffects) {
		if f.Status == "OPEN" {
			pkg.OpenFindings = append(pkg.OpenFindings, f)
		}
	}
	return pkg, nil
}

func (s *Store) CheckGate(respID, gate string) (GateResult, error) {
	conds, ok := GateDefinitions[gate]
	if !ok {
		return GateResult{}, fmt.Errorf("unknown_gate: %q", gate)
	}
	res := GateResult{Gate: gate, Passed: true, Results: map[string]string{}}
	for _, c := range conds {
		var pass bool
		var reason string
		if c.EvidenceRequired {
			pass, reason = s.latestEvidencePasses(respID, gate, c.Check)
		} else if fn, ok := simpleChecks[c.Check]; ok {
			pass, reason = fn(s, respID)
		} else {
			pass, reason = false, "no checker registered for "+c.Check
		}
		if pass {
			res.Results[c.Check] = "pass"
		} else {
			res.Results[c.Check] = reason
			if c.Required {
				res.Passed = false
			}
		}
	}
	return res, nil
}

func (s *Store) latestEvidencePasses(respID, gate, check string) (bool, string) {
	rows, err := s.db.Query(`

		WHERE project_id = ? AND type = 'GateEvidence'
		  AND json_extract(props,'$.responsibility_id') = ?
		  AND json_extract(props,'$.gate') = ?
		  AND json_extract(props,'$.check') = ?

# Two modes, wired to two events in settings.json:
#   PostToolUse on mcp__minidde__check_gate  → mint a flag on pass
#   PreToolUse  on mcp__minidde__update_status → block gated statuses
set -uo pipefail
cd "$(git rev-parse --show-toplevel 2>/dev/null || pwd)"
FLAGDIR="${HOME}/.minidde/gate-flags"; mkdir -p "$FLAGDIR"
INPUT=$(cat)
TOOL=$(jq -r '.tool_name // ""' <<<"$INPUT")

if [[ "$TOOL" == "mcp__minidde__check_gate" ]]; then
  # PostToolUse: on a passing result, mint the flag.
  RESP=$(jq -r '.tool_input.responsibility_id // ""' <<<"$INPUT")
  GATE=$(jq -r '.tool_input.gate // ""' <<<"$INPUT")
  PASSED=$(jq -r '.tool_response.content[0].text // "{}"' <<<"$INPUT" \
           | jq -r '.passed // false' 2>/dev/null)
  if [[ "$PASSED" == "true" && -n "$RESP" && -n "$GATE" ]]; then
    touch "$FLAGDIR/gate-${RESP}-${GATE}"
  fi
  exit 0
fi

if [[ "$TOOL" == "mcp__minidde__update_status" ]]; then
  TO=$(jq -r '.tool_input.to // ""' <<<"$INPUT")
  ID=$(jq -r '.tool_input.id // ""' <<<"$INPUT")
  declare -A REQUIRED=(
    [DESIGN_COMPLETE]="design_exit"
    [BUILT]="build_exit"
    [COMPLETE]="acceptance_exit"
  )
  GATE="${REQUIRED[$TO]:-}"
  [[ -z "$GATE" ]] && exit 0   # entry statuses pass freely

BLOCKED: $ID → $TO requires a passing '$GATE' gate check first.
Remedy: submit any missing evidence (submit_gate_evidence), then run
check_gate(responsibility_id="$ID", gate="$GATE"). When it passes,
retry this transition.
EOF
    exit 2
  fi

  exit 0
fi

func (s *Store) ClaimWork(sessionID, wpID string) (bool, error) {
	res, err := s.db.Exec(`

		  updated_at = strftime('%Y-%m-%dT%H:%M:%SZ','now')
		WHERE id = ? AND project_id = ? AND type = 'WorkPackage'
		  AND status IN ('NOT_STARTED','SPECIFIED')`,

		VALUES (?,?,?,?,?,strftime('%Y-%m-%dT%H:%M:%SZ','now'))`,

func (s *Store) Book(ctx context.Context, reqID string) (string, error) {
	tx, err := s.db.BeginTx(ctx, nil)
	if err != nil {
		return "", fmt.Errorf("begin: %w", err)
	}
	defer tx.Rollback()

	// Guarded single-winner update: rows-affected 0 = already booked.
	res, err := tx.Exec(`UPDATE booking_request SET status='booked'
		WHERE id=? AND status='submitted'`, reqID)
	if err != nil {
		return "", fmt.Errorf("%w: guard: %v", ErrStore, err)
	}
	if n, _ := res.RowsAffected(); n == 0 {
		return "", ErrConflict // caller maps to 409 / handled-and-nil
	}

	sap := mintSAPNumber() // "SAP-2026-000042"-shaped, sequence from a table
	if _, err := tx.Exec(`INSERT INTO contract
		(sap_contract_number, lifecycle_state, booked_at)
		VALUES (?, 'active', ?)`, sap, now()); err != nil {
		return "", fmt.Errorf("%w: contract: %v", ErrStore, err)
	}

	evt, err := envelopeContractBooked(sap, reqID) // pkg/contracts types
	if err != nil {
		return "", err
	}
	if err := outbox.InsertTx(tx, evt); err != nil {
		return "", fmt.Errorf("%w: outbox: %v", ErrStore, err)
	}
	return sap, tx.Commit()
}

func (h *Handler) Events(w http.ResponseWriter, r *http.Request) {
	var evt events.Event
	if err := json.NewDecoder(io.LimitReader(r.Body, 1<<20)).Decode(&evt); err != nil {
		http.Error(w, "bad envelope", http.StatusBadRequest) // poison: don't retry
		return
	}
	fresh, err := h.store.MarkConsumed(r.Context(), evt.ID) // INSERT OR IGNORE
	if err != nil {
		http.Error(w, "ledger", http.StatusInternalServerError) // NACK
		return
	}
	if !fresh {
		w.WriteHeader(http.StatusOK) // duplicate: converge quietly, ACK
		return
	}
	if err := h.dispatch(r.Context(), evt); err != nil {
		http.Error(w, err.Error(), http.StatusInternalServerError) // NACK → redelivery
		return
	}
	w.WriteHeader(http.StatusOK)
}

Why it exists

The outbox is the distributed-systems lesson of the real repo: every producer writes state + outbox row in one transaction, a drainer publishes, consumers dedup on event_id, and a republish re-sends the same id so a correct consumer converges. Every piece exists because the naive alternative (publish-after-commit, or commit-after-publish) loses or duplicates events under crash — there is no third option, only the outbox.

Doctrines worth memorizing

  • Graph first — query before grepping; if it isn't an edge, it doesn't exist.
  • The contract is the specification — "not built yet" is never a reason.
  • Statuses move through the map — one writer, reasons required, changelog always.
  • Server allocates IDs — parallel authors, zero collisions.
  • Evidence beats assertion — "passed" must be distinguishable from "did not run".
  • Zero internal deferrals — external dependency + DA authorization, or do the work.
  • Advisory is a state with an owner and an exit criterion — a rule violated twice becomes a hook.
  • The server derives, the UI projects — derived state has a sole writer.
  • Confusion surfaced beats confusion buried — register the finding, register the escalation, stop guessing.
  • Verify, don't assume — read the write back; run the test; the output is the truth.
